FILLING · RELAY NOT ASSIGNED

Water pump cycle

Choose Filling to add water to the 55-gallon drum, or Tank-to-tank to move water from the drum to the display tank above. Each run uses that pump’s selected overflow sensors and cooldown.

The first run starts after the interval, once the operating window and safety checks allow it.

Saving applies lighting changes immediately. Watering starts after the configured interval. Paused schedules stay paused.

Each manual run stops automatically when its timer ends. Stopping an output also pauses schedules and stops scheduled runs. Assign relay functions →

Built-in pump protection

Loading runtime and cooldown limits

Only one water pump can run at a time. A selected sensor blocks and stops its assigned pumps when it triggers or becomes unavailable. Filling is limited to 5 minutes; draining and tank-to-tank to 10 minutes, or your lower runtime limit.

TWO OVERFLOW SENSORS

Overflow sensor stops

Name each sensor for its location, then choose which sensors stop each pump. Sensor 1 is Arduino D2; sensor 2 is D4. These assignments follow the pump function when you change relays.

A selected sensor blocks starts and stops an active run on overflow, missing data, or stale data. “No overflow stop” disables that protection for the chosen pump; runtime, cooldown, and emergency stop still apply.

Stop all outputs before saving. Changes leave schedules paused until you resume them.
