    Water pump cycle

    Choose Filling for the 55-gallon drum, or Tank-to-tank for the display tank above. Each run uses that pump’s selected overflow sensors. Equal window times mean all day.

    Assign relay in Setup →

    The first run starts after the interval. If a run lasts longer than its repeat interval, the next run waits for it to finish.

    Lighting changes apply immediately. Changing watering stops its scheduled run and restarts the interval. Paused schedules stay paused.

    Each relay runs until you press Stop, even if you close this page. Relays and water pumps can run together; there are no cooldowns or runtime caps. Stopping an output also pauses schedules and stops scheduled runs. Assign relay functions →

    TWO OVERFLOW SENSORS

    Overflow sensor stops

    Name each sensor for its location, then choose which sensors stop each pump. Sensor 1 is Arduino D2; sensor 2 is D4. These assignments follow the pump function when you change relays.

    A selected sensor blocks starts and stops an active run on overflow, missing data, or stale data. “No overflow stop” disables that protection for the chosen pump. Emergency stop and the external safety switch still apply.

    Stop all outputs before saving. Changes leave schedules paused until you resume them.

    WATER PUMPS

    External safety switch

    Manual relay controls have no runtime caps, cooldowns, or operating-hour restrictions. This optional physical switch applies to all water pumps. Stop active outputs before changing its wiring settings.

    The switch input must be HIGH for pumps to run. A LOW or unavailable input blocks and stops pumping.
